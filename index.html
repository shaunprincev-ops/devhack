PROJECT INFORMATION

About & safety

What this prototype does — and does not do.

✓

What works in this prototype

  • Offline-capable website shell after initial setup
  • Local CBC model inference after training and caching
  • Held-out evaluation metrics written by the training script
  • Local research-demo records and JSON export
  • Network status indicator
!

Limitations

  • Small, single-site dataset; unknown generalisation to other populations
  • Model does not use haemoglobin or hematocrit as input
  • Model score is not a calibrated clinical probability
  • 0.5 model boundary is not a clinical referral threshold
  • Local browser storage is not secure clinical record management
⚕

Required disclaimer

PHC Assist is an experimental decision-support concept, not a diagnostic device. The CBC model is an educational research baseline and is not clinically validated. It must not be used to diagnose or rule out anaemia, determine treatment, or make patient referral decisions. A lower model score does not mean a person is free of anaemia. Use appropriate laboratory haemoglobin testing and qualified clinician assessment. Any future clinical use requires independent external validation, subgroup evaluation, clinical review, privacy safeguards, and applicable regulatory review.

Offline model inference

The trained model is a small JSON file evaluated directly in the browser, so no remote inference service is required. The app must load once with the model installed before it can use that model offline. Skin and vitals pathways remain demos.
